🏥 MetroMed - Практический Проект Веб-Разработки
Добро пожаловать в репозиторий MetroMed! Это мой первый полноценный веб-сайт, разработанный в качестве учебного проекта для закрепления базовых навыков веб-разработки.

--------------------------------------------------------------------------------------------------

🚀 Цель Проекта
Этот сайт создан с единственной целью: практика.

Демонстрация Базовых Навыков: Показать, что я могу создавать полноценные веб-страницы с нуля.

Освоение Основных Технологий: Закрепить знание о том, как HTML, CSS и JavaScript работают вместе для создания интерактивного интерфейса.

Обучение: Я являюсь начинающим (новичком) в веб-разработке, и этот проект служит площадкой для экспериментов и совершенствования моих навыков в чистом коде и адаптивном дизайне.

--------------------------------------------------------------------------------------------------

🛠️ Используемые Технологии
Сайт MetroMed полностью построен на трех ключевых технологиях:

HTML5 (HyperText Markup Language):

Использовался для создания логической и семантической структуры всего контента сайта (заголовки, параграфы, навигационные элементы, секции).

CSS3 (Cascading Style Sheets):

Применялся для стилизации и оформления. Включает использование Flexbox и/или Grid для создания адаптивной верстки, визуальных эффектов и обеспечения приятного пользовательского опыта на разных устройствах.

JavaScript (JS):

Использовался для добавления интерактивности на сайт. Ключевыми элементами, реализованными на JS, являются динамическое меню и простой слайдер/карусель.
